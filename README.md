A simple Python implementation of the Caesar Cipher completed as part of the freeCodeCamp Python curriculum. The project demonstrates basic text encryption and decryption using alphabet shifting, with support for uppercase letters, ROT13, and input validation.
 
## Features
- Encrypt and decrypt text  
- ROT13 support  
- Uppercase and lowercase handling  
- Input validation  
- Fully commented, beginner‑friendly code
 
## How It Works
The Caesar cipher shifts each letter by a fixed number. Python’s `str.maketrans()` and `translate()` are used to efficiently map characters to their shifted equivalents.
